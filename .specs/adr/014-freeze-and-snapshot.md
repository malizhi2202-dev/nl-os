# ADR-014: 固化（freeze）与快照/撤销格式

- **状态**: accepted
- **日期**: 2026-10-25
- **关联**: `ADR-003`（`.tools` 语法）、`ADR-012`（能力 ID）、G1 安全审计师三条条件

## Context

固化解决"同一套操作每次都要过模型"的浪费；撤销解决"误操作不是终局"。两者都涉及文件落盘，会被当作攻击面。

关键约束（G1 安全审计师条件）：
- 固化文件必须带校验和，执行前校验
- 快照不得包含敏感内容（`~/.ssh` 等）
- 快照容量上限必须在 DESIGN 定死
- 需求门补充：索引与快照文件权限 0600；敏感清单可配置；并发互斥

## Decision

### 固化文件格式（向后兼容扩展）

```
# @format: 2
# @checksum: sha256:<64 hex>
# @cap: create_dir name=build,location=.
# @cap: run_cmd argv=cmake,..
运行 cmake -S . -B build ...
```

- **旧格式（无 `# @` 头）继续按 v1 解析**，只是不享受冻结保证，执行时打印"未固化脚本（将经模型）"
- `# @checksum` 覆盖**头部之后的正文档**：`sha256(正文原文)`
- `# @cap` 记录每步绑定的能力 ID 与槽位值；执行时若能力 ID 在注册表中不存在 → **fail-fast，不执行任何步骤**
- 校验和不匹配 → 拒绝执行，报出被改动的行号（用正文 hash 定位到首个差异行需逐行累积，实现上记录每行的链式 hash）
  - 简化决策：**逐行链式 hash**（`h_i = sha256(h_{i-1} + line_i)`，头部记录最终 `h_n`），可精确定位首个不一致行

### SHA-256 的来源

- **内置实现**（约 150 行，public-domain 风格），用 NIST 标准测试向量覆盖（空串、`"abc"`、长串）
- 理由：ADR-006 限定外部依赖 ≤3（ggml / cJSON / 测试框架），不能为哈希引入 OpenSSL 或 libsodium
- **诚实边界**：无密钥的校验和只能防**误改与损坏**，不能防**恶意重算**。防恶意依赖 `0600` + 目录属主 + 审计留痕，不声称提供签名保证。此残余风险在 DESIGN 风险表登记。

### 快照与撤销

- 位置：`${XDG_STATE_HOME:-~/.local/state}/nl-os/snapshots/<epoch_ms>/`，目录与文件权限 **0600**
- 快照对象：仅 **L2/L3 操作**、且被修改的单个文件 ≤ **8MB**；目录删除按目录递归累计计算，累计超 8MB 则**不自动快照**，改为在确认提示中明确写"该操作不可撤销"
- 敏感排除（可配置，默认含）：`~/.ssh` `~/.gnupg` `~/.aws` `~/.kube` `*.pem` `*.key` `*.p12` `*secret*` `*token*` `*password*`；命中即跳过并在审计中记 `skipped-sensitive`
- 容量：总上限 **200MB**，LRU 淘汰；保留最近 **10** 次操作；淘汰与超限都在审计中留痕，不静默失败
- 并发：`flock` 锁 `snapshots/.lock`，写快照与淘汰互斥
- 撤销：`nlsh --undo [N]` 默认 1；只能撤销仍在快照保留窗口内的操作；已淘汰 → 明确报"不可撤销"而非静默成功

## Consequences

- ✅ 冻结脚本可在断网无模型下确定性重放；被改动会被发现并拒绝
- ✅ 撤销边界清晰（8MB/10 次/200MB），端侧磁盘不会被吃光
- ✅ 敏感内容不出现在快照里，即使撤销能力本身有 bug 也不会泄露密钥
- ❌ 内置 SHA-256 是新增约 150 行安全相关代码，需单独代码审查与测试向量（纳入 TEST 阶段）
- ❌ 8MB 上限意味着大文件（视频/镜像）操作不可撤销，用户必须理解这个边界
- ❌ 逐行链式 hash 使大脚本固化的 CPU 成本线性增长（实测可控：1000 行约几 ms）

## 被否掉的备选

| 备选 | 否掉原因 |
|---|---|
| 用 OpenSSL / libsodium 做 SHA-256 | 违反 ADR-006 依赖上限；端侧交叉编译成本高 |
| 用 FNV-1a / CRC32 | 碰撞容易，安全专家否决 |
| 给 `.tools` 做公私钥签名 | 端侧无 PKI、无密钥管理方案；超出本 change 范围（记入 v2） |
| reflink / 文件系统级快照 | OpenWrt 的 fs 不支持；不可移植 |
| 快照所有文件（不设上限） | 端侧 4GB SD 卡会被吃满 |
