# ADR-022 · 决策层兜底：认得出工具就用"审查过的只读默认参数"执行

- 状态：已采纳
- 日期：2026-10-25
- 相关：ADR-012（能力注册表/权限表）、ADR-013（类型化决策层）、ADR-021（常驻进程）、change `decision-fallback`

## 背景

规则未命中时，原来只有一条出路：模型的**自由生成**（`nl_intent_extract` 让模型吐一段 JSON
再解析成命令）。实测这条路：

- 单次 20–30s（128 token 生成 × 最多 3 次重试，2 vCPU）
- 对绝大多数输入返回"无法理解"（`显示当前工作目录`、`查看端口占用` 都是）
- 之前还会 `GGML_ASSERT` 直接 abort（ADR 同批修复）

而项目的**决策层**（候选收缩 + 受约束 Choice）是毫秒级的，只是它只回答"这是哪个工具"，
不回答"用什么参数"。所以决策层一直只服务于 `--decide` 和评测，没接进 `nlsh -c`。

## 决策

在规则层与模型层之间插一层**兜底**：候选收缩认出工具 → 查"只读默认参数表" → 拼成命令 →
走原有的确认门/权限/快照/审计执行。

四级解析顺序（`dispatch.c: parse_smart`）：

```
1. 本地规则（免费，~0.04s）
2. 决策层兜底（毫秒级，不加载模型）   ← 本 ADR
3. 常驻进程（模型只加载一次，推理仍 20s 量级）
4. 进程内加载（原行为）
```

## 安全边界（这是本 ADR 的核心，不是细节）

扫描器把**所有**未标注能力一律当 `effect: delete`、`perm: L4`（deny-by-default）。
所以"从注册表推断它是只读"这条路走不通——必须显式列出。

1. **只对 `capability_perm_map.h` 里的 L1 能力生效**：`perm_level != 1` 一律跳过
   （L2 需确认、L3 高危、L4 禁止，都不是"兜底"该干的事）。
2. **参数只能是本文件里的字面量**：`READ_DEFAULTS` 是一张 10 条的固定表
   （`pwd`/`ls -la`/`ps aux`/`df -h`/`free -m`/`uptime`/`whoami`/`uname -a`/`date`/`lsof -i -P -n`），
   不接受任何来自输入或模型的参数拼接——注入面为零。
3. **表外工具不猜**：即使决策层认出来了（比如 `grep`、`du` 需要路径参数），也不执行，
   继续走模型或如实拒绝。
4. **网络查看用 L1 的 `lsof`**，不放行 `ss`/`netstat`——它们在权限表里没登记 = L4，
   本 ADR 不借兜底之名放宽权限。

## 后果

实测（`--no-model`，即完全不加载模型）：

| 输入 | 改动前 | 改动后 |
|---|---|---|
| `显示当前工作目录` | 无法理解（20s） | `pwd` **11ms** |
| `看看磁盘还剩多少` | 无法理解（20s） | `df -h` **12ms** |
| `内存还剩多少` | 无法理解（20s） | `free -m` |
| `当前用户是谁` | 无法理解（20s） | `whoami` |
| `系统信息是什么` | 无法理解（20s） | `uname -a` |
| `查看端口占用` | 无法理解（20s） | `lsof -i -P -n` |
| `现在几点` | 无法理解（20s） | `date` |

召回抽样：12 句里 **9 句**由规则或决策层直接决定（此前约 2 句），剩余 3 句是
"写首诗""从日志里挑错误"这类确实需要参数或能力的，如实拒绝。

顺带扩了 `decision.c` 的同义词词典（`显示`/`工作目录`/`端口`/`内存`/`负载`/`几句`…），
并给词条加了权重——否则 `显示当前工作目录` 会在 `ls` 和 `pwd` 之间打平（泛词 6、特指 10）。

## 备选与否决

| 方案 | 否决理由 |
|---|---|
| 让模型输出"工具 + 参数"（受约束 grammar） | 需要二次解码，慢；且参数仍不可信，等于把注入面交回模型 |
| 用注册表的 effect 判断只读 | 扫描器一律标 delete，判断不出来；改成"扫描器猜 effect"风险更大 |
| 放宽 `ss`/`netstat` 到 L1 | 权限表是唯一权威，兜底机制不该顺手改权限策略 |
| 对表外工具用"无参数调用"（如 `grep`） | 无参数会读 stdin 挂住终端，或行为不可预期 |
