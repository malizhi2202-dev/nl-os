# ADR-019 · 统一确认门（三套策略收敛为一套）

- **状态**: 已接受（2026-10-25）
- **背景 change**: `nlsh-exec`
- **相关**: ADR-002（L1–L4 权限）、ADR-014（固化与快照）、ADR-017（broker fail-closed）

---

## 1. 问题

`nlsh-exec` 把自然语言执行接进 `nlsh` 后，同一个产品里出现了三套确认语义：

| | `nlsh` 自然语言 | `nl-run` `.tools` | `nlsh` 传统命令（快路径） |
|---|---|---|---|
| 何时问 | `needs_confirm \|\| perm>=2` | `needs_confirm && !allow_l2` | 从不 |
| 接受什么回答 | `y / Y / yes / 是` | 必须 `yes` 开头（**`y` = 取消**） | — |
| 怎么绕过 | `NL_ASSUME_YES=1` | 脚本头 `# @perm: allow-l2` | — |
| 取消退出码 | `1` | 步骤序号 `i+1` | — |
| 快照 | 写操作执行前 | 同 | 无 |
| 审计 | 有 | **完全没有** | 有 |

后果：用户肌肉记忆互相冲突（`y` 在一处同意、在另一处取消）；`# @perm: allow-l2` 实际会豁免
**L3 删除**（名字说 L2，行为到 L3）；`.tools` 删完东西后在审计里查不到。

## 2. 专家团讨论

四位角色各自立场与让步：

**产品经理**：主张"用户在哪里按的键，就应该在哪里得到一致的回应"。反对 `nl-run` 里 `y` 算取消
（这是纯粹的陷阱）。对快路径的态度是"不要加确认"——用户自己敲的就是 shell 命令，`nlsh`
不该比他懂的更多；但要求**可撤销**。

**用户评测员**：主张一套词表、一个绕过开关、一个取消码。反对为快路径加确认（会让
`nlsh` 变得比 bash 更难用，用户会绕开它）。同意快路径加"破坏性命令留快照"。

**架构师**：指出根因是"确认"被复制了三份而不是一个模块；要求抽 `confirm.c`，
并反对在 `nl-run` 里继续用 `strncmp(yn,"yes",3)` 这种就地判断。

**安全审计师**：三条底线——① `allow_l2` 必须真的只到 L2；② 取消一律 fail-closed；
③ `.tools` 的执行必须留审计（"谁在什么时候删了什么"是最基本的问题）。
在快路径上退让：**不要求确认**（与传统 shell 等价），但要求破坏性命令留快照。

**裁决（无反对票，安全审计师的 3 条底线全部采纳）**

## 3. 决策

- **P-1 触发条件**：`nl_confirm_required(needs_confirm, perm_level)`——写操作或 L2+ 才问；只读不问。三处共用。
- **P-2 回答词表**：`y / Y / yes / YES / 是`（前缀）即同意；**空行 = 取消**（默认 No）；EOF = 取消。
- **P-3 绕过开关**：`NL_ASSUME_YES=1` 为唯一全局开关；`nlsh --yes` / `nl-run --yes` 设同一项。
  `# @perm: allow-l2` 保留但**语义收窄**为"仅豁免 L2"，L3+ 一律问。
- **P-4 退出码**：`0` 成功 / `1` 失败或拒绝 / `3` 用户取消（`nl-run` 不再返回步骤序号）。
- **P-5 审计**：`nl-run` 每步写审计（`capability_id` / `result` / `duration_us` / 取消原因 `user-declined`）；
  `nlsh` 快路径的破坏性命令（`rm/mv/dd/shred/truncate/mkfs/fdisk/wipefs`）**执行前留快照**，
  审计 `reason` 标 `fast-path-destructive`。
- **P-6 快路径不问**：传统命令保持 shell 语义（用户已明确敲了命令），但不再"无痕"：有快照、有审计。

## 4. 后果

**好的**：一处实现、一套词表、一个开关、一个取消码；`.tools` 的事后追查能力从无到有；
`allow-l2` 不再意外豁免删除；`nlsh` 里手滑 `rm -rf` 可以 `--undo`。

**代价**：`nl-run` 取消的退出码从"步骤序号"变成 3——依赖"序号即失败步"的脚本需改；
快路径破坏性命令多一次快照尝试（几十毫秒，超限则跳过并告警）。

**不做**：不给快路径加确认（专家团一致反对）；不做"记住用户选择 N 分钟"这类隐式信任
（`NL_ASSUME_YES` 已足够，隐式窗口难以审计）。
