## 本轮评审发现并已修的问题

| 问题 | 严重度 | 证据 | 修复 |
|---|---|---|---|
| Release 构建无法通过（`-Wformat-truncation` ×2、`-Wunused-result` ×3） | **高**：等于"发布配置根本编不出来" | `cmake -DCMAKE_BUILD_TYPE=Release` 报 5 处 error | `snapshot.c` 用精度限定符；`capability_scan_test.c` 检查 `symlink` 返回值；`adapter_http_test.c` 检查 `freopen` |
| `--eval` 输出的 `input` 未做 JSON 转义 | 中：输入含引号时整行 JSON 非法 | `{"input":"查看 \"quoted\" 文件"}` | 加 `json_escape()`，实测可被 `json.loads` 解析 |
| `download_model.sh` 目录不可写时失败仍退出 0；对已完整文件 `-C -` 得 416 后**误删模型** | 高（数据丢失） | 本会话真实发生：428MB 模型被删后重下 | 改为幂等（先校验已存在文件）+ 下载到 `.part` 校验后 `mv` + 失败退出非 0 |
| prompt 超过 `n_ctx` 时依赖 `llama_decode` 报错 | 低 | 代码审查 | 显式 `n > n_ctx` 直接返回 -1 |
| `--no-model` 对 `--decide` 不生效 | 低 | 语义不一致 | 透传 `no_model` |

## 未闭环项（进入 G4 / 后续迭代）

1. **候选召回 67%**（漏救 33%，平均候选 0.85）：决策层当前最大误差源。模型在候选内 98.5% 的准确率
   被上一层吃掉。**下一步优先级最高**。
2. **B 档 P95 2788ms** 未达 1.5s：本机 2 vCPU + 内存余量 300MB，不能代表目标硬件；
   但即便换硬件，当前"每次全量 prefill、清 KV"的实现也偏浪费，prefix cache 是必要优化。
3. **快路径 ≈30ms** 未达 5ms：需懒加载注册表或常驻 daemon。
4. **置信度指标无区分度**：需候选间相对概率（K 次前向），在延迟解决前不做。
5. **Noul 模型信号未接**：模型只能影响 Choice，不能抬升 allow→confirm。
6. **C 档 / ARM64 / musl 未验证**：沿用 G4 架构师的显式降级标注。
