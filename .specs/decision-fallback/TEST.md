# TEST — decision-fallback

## 1. 自动化

| 套件 | 数量 | 结果 |
|---|---|---|
| `ctest` | 34 | **34/34 通过**（新增 `decision_cmd`） |
| `scripts/verify_exec.sh` | 84 断言 | **84 通过 / 0 失败**（新增 AC-15 三条） |
| `scripts/verify_hook.sh` | 35 断言 | **35 通过 / 0 失败** |

`tests/unit/decision_cmd_test.c` 固定了五件事：

1. 表内命中：`显示当前工作目录` → `pwd`（L1、不需确认、`source=DECISION`）
2. 参数固定：`看看磁盘还剩多少` → `df -h`
3. **高危不兜底**：`删除 /tmp/somewhere`（`rm` 是 L3）→ 返回 0，不产出命令
4. **表外不猜**：`统计行数 wc`（L1 但不在默认参数表）→ 返回 0
5. 无候选：`帮我写一首关于春天的诗` → 返回 0

## 2. 实测（`--no-model`，证明完全不加载模型）

| 输入 | 改动前 | 改动后 |
|---|---|---|
| `显示当前工作目录` | 无法理解（20–30s） | `→ /usr/bin/pwd` **11ms** |
| `看看磁盘还剩多少` | 无法理解 | `→ /usr/bin/df -h` |
| `内存还剩多少` | 无法理解 | `→ /usr/bin/free -m` |
| `当前用户是谁` | 无法理解 | `→ /usr/bin/whoami` **12ms** |
| `系统信息是什么` | 无法理解 | `→ /usr/bin/uname -a` |
| `查看端口占用` | 无法理解 | `→ /usr/bin/lsof -i -P -n`（L1） |
| `现在几点` | 无法理解 | `→ /usr/bin/date` |

召回抽样（12 句）：**9 句**由规则或决策层直接决定（此前约 2 句）。

## 3. 安全边界实测

```
$ nlsh --no-model -c '删除 /tmp/nl_safe_probe 目录'
⚠️ 需要确认 (L3): rm -rf /tmp/nl_safe_probe
执行? [y/N]
已取消（无输入）
目录还在吗: 是          ← 高危命令没有被"兜底"绕过确认
```

`safe_probe` 目录保留、未被删除；`rm` 走的是原有 L3 确认门，不是兜底默认参数。

## 4. 回归中暴露的一处断言失效

`AC-14 规则未命中：真加载模型` 原本用 `显示当前工作目录` 当例子。本 change 之后这句
由决策层兜底、**不再加载模型**，断言直接变红（RSS 19MB，而不是 >300MB）。

处理：换成真正需要模型的句子（`总结一下这个目录是干什么用的`，实测 815MB / 29.6s），
并把新行为单独锁成 AC-15——不是把断言改松，而是把**前提变化**显式登记下来。

另有两个"看着合适其实不合适"的候选输入被否掉：

- `帮我把日志里的错误挑出来并汇总` → 被复杂度预算层先拒绝（`替代步骤：cli:ls、cli:stat、cli:cat`），到不了模型层
- `把上周的截图按日期重命名` → 决策层有 `mv` 候选（L2，不兜底）但预算层先拒，0.21s 返回

## 5. 已知未覆盖

| 项 | 说明 |
|---|---|
| 需要路径参数的工具（`grep`/`du`/`cat`） | 兜底不支持，仍走模型或如实拒绝 |
| 推理本身的速度 | 未改善（模型层瓶颈，见 ADR-021） |
| 跨发行版默认参数 | `ps aux`/`lsof -i` 在极少数系统可能不适用，只影响输出不影响安全 |
